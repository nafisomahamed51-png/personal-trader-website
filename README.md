Mashruuc dhammaystiran oo heer sare ah (Premium Financial Institution Aesthetic) oo loogu talagalay trader xirfadle ah. - **Trades-kii Ugu Dambeeyay:** Ticker muujinaya 4-tii trade ee ugu dambeysay oo leh natiijooyinkooda.

### 2. Bogga Xogta Shakhsiga — About Me
- **Taariikhda Trader-ka:** Khibrad 6+ sano ah, xarumaha shaqada (Mogadishu & London Desk).
- **Suuqyada uu ka Shaqeeyo:** XAU/USD (Gold), EUR/USD, NAS100, GBP/JPY, BTC/USD.

### 3. Dashboard-ka Waxqabadka — Trading Performance
- **Jaantuska Equity Curve:** Recharts AreaChart oo leh gradient dahab iyo cagaar ah, tilmaamo qoto dheer (Tooltips), iyo xisaabinta Drawdown-ka.
- **Jaantuska Faa'iidada Bil Kasta (Monthly P&L):** BarChart muujinaya bil kasta faa'iidada (Cagaar) ama khasaaraha (Casaan).
- **Tirooyinka Muhiimka ah:**
  - Win Rate % iyo Loss Rate %
  - Tirada Trades-ka Guulaystay, Khasaaray, iyo Break-Even
  - Celceliska Faa'iidada (Average Win) iyo Celceliska Khasaaraha (Average Loss)
  - Profit Factor & Win/Loss Ratio
  - Maximum Drawdown ($ iyo %)
  - Net Profit ($ iyo %)
- **Waxqabadka Suuq Kasta:** Forex, Metals, Indices, iyo Crypto oo la barbar dhigay.
- **Waxqabadka Istaraatiijiyad Kasta:** SMC Liquidity Sweep, Trend Continuation, FVG Retest, iwm.
- **Filtarrada Firfircoon (Dynamic Filters):**
  - Muddada Taariikhda: Dhammaan, 30 Maalmood, 90 Maalmood, Sanadkan (YTD)
  - Suuqa ama Trading Pair-ka
  - Istaraatiijiyadda
  - Natiijada (Wins, Losses, Break-Even)

### 4. Diiwaanka Trades-ka — Trading Journal
- **Nidaam Buuxa oo CRUD ah:**
  - **Ku dar Trade Cusub:** Foom la hubiyo oo toos u xisaabiya P&L, Lots, iyo R:R marka la geliyo Entry, Exit, SL, TP, iyo Size.
  - **Wax Ka Beddel Trade:** Beddel xog kasta oo trade hore u jirtay.
  - **Tirtir Trade:** Modal xaqiijin ah oo ka hortagaya tirtirid lama filaan ah.
  - **Eeg Faahfaahinta (Detail View):** Kaadh muujinaya sababta farsamo, dareenka nafsiga ah (Psychology), casharrada laga bartay, iyo sawirka chart-ka oo weyn.
- **Raadinta & Shaandheynta:** Raadi pair, strategy, ID, ama sabab; ku kala hormari taariikhda, P&L-ka, ama R:R-ka.
- **CSV Export & Import:**
  - Dhoofi dhammaan diiwaanka trades-ka adigoo gujinaya *"Dhoofi CSV"*.
  - Soo geli fayl CSV ah adigoo isticmaalaya nidaamka xaqiijinta (validator) oo hubiya tiirarka iyo xogta ka hor inta aan la keydin.
  - Soo degso Template-ka CSV-ga.

### 5. Maaraynta Khatarta — Risk Management Calculator
- **Xogta La Geliyo:**
  - Lacagta koontada ku jirta (Account Balance $)
  - Boqolkiiba khatarta (Risk % oo leh slider iyo badhamo 0.5%, 1%, 1.5%, 2%, 3%)
  - Nooca suuqa: Forex (pips), Dahab/Metals (100 oz lots), Indices (points), Crypto (coins)
  - Qiimaha gelitaanka (Entry), Stop-Loss (SL), iyo Take-Profit (TP)
- **Natiijooyinka Tooska ah:**
  - Lacagta ugu badan ee khatarta la gelinayo ($ Max Risk)
  - Cabbirka la soo jeedinayo (Recommended Lot Size)
  - Farqiga qiimaha stop-loss-ka (Distance in pips/points)
  - Faa'iidada la filan karo ($ Potential Profit)
  - Saamiga Risk-to-Reward (R:R)
  - Digniin haddii khatartu ka badato 2% (Over-Risk Warning)
  - Sharaxaadda qaacidadada xisaabta (Formula Breakdown)

### 6. Falanqaynta Suuqyada — Market Analysis
- **Madal Qoraallada lagu Daabaco:** Trader-ku wuxuu daabaci karaa falanqayntiisa farsamo.
- **Qaybaha & Tags:** Forex, Metals, Indices, Crypto, iyo Psychology.

- **Calaamadda Tusaalaha:** Dhammaan falanqaynta tijaabada ah waxaa si cad loogu calaamadeeyay *"Falanqayn Tusaale ah / Waxbarasho"*.

## 🚀 Sida Loo Rakibo Loona Socodsiiyo (Installation & Development)

### Shuruudaha:
- **Node.js:** v18 ama ka cusub
- **npm:** v9 ama ka cusub

### 1. Soo Degso ama Fur Folder-ka:
```bash
cd "c:\Users\hp\Desktop\Personal Website"
```

### 2. Rakib Dependencies-ka:
```bash
npm install --legacy-peer-deps
```

### 3. Ku Socodsii Qaabka Horumarinta (Dev Server):
```bash
npm run dev
```
Fur biraawsarkaaga: `http://localhost:5173`

### 4. Dhis Nooca Wax-soo-saarka (Production Build):
```bash
npm run build
```
Faylasha la habeeyay waxay gelayaan folder-ka `dist/`.

### 5. Fiiri Nooca Build-ka ah (Preview):
```bash
npm run preview
```
